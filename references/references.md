# References

Use this file to list clips and moments you love. The `npm run refs` script reads this file and generates contact sheets.

## Format

One section per clip. List every moment with a time range and a short note.

```
## clip-name.mp4
- 00:07-00:09 - what happens on screen - why I like it
- 00:15-00:18 - what happens on screen - why I like it
```
