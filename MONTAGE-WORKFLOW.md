# Montage Workflow Guide

How to create a travel, event, product, or B-roll montage in VideoStudio.

---

## Step 1: Create the project

```bash
npm run new-video my-trip --type montage
```

This creates:
```
assets/projects/my-trip/
  BRIEF.md              ← montage brief template
  broll/                ← drop your clips here
  audio/                ← drop your music here
  screenshots/
  footage/
  processed/
```

---

## Step 2: Add media

- Drop B-roll clips (MP4, MOV) into `assets/projects/my-trip/broll/`
- Drop music (MP3, WAV, M4A) into `assets/projects/my-trip/audio/`

---

## Step 3: Run prep

```bash
npm run prep-montage my-trip
```

This outputs to `work/my-trip/prep/PREP.md`:
- Probed clip info (codec, resolution, fps, duration)
- B-roll contact sheets (screenshots of each clip)
- Shot list with frame boundaries
- Beat map from music (BPM, beat frames, per-beat timing)

---

## Step 4: Detect beats (optional, for better results)

```bash
npm run beat-map my-trip
```

This outputs `work/my-trip/prep/refs/beat-map.json`:
- BPM, total beats, beat frame positions
- Uses aubio if available, ffmpeg transients as fallback
- Install aubio for best results: `pip install aubio`

---

## Step 5: Fill the brief

Open `assets/projects/my-trip/BRIEF.md` and fill in:
- Concept
- Shot list (which clip → which beat → what happens)
- Titles and labels
- Transition style
- Color grade
- Don't want

---

## Step 6: Create the composition

```bash
# Copy the scaffold
cp -r src/videos/montage-template src/videos/my-trip
```

Edit `src/videos/my-trip/index.tsx`:
1. Fill `SHOT_LIST` with your clip paths and frame positions
2. Load the beat map from `work/my-trip/prep/refs/beat-map.json`
3. Set up title card and labels
4. Register in `src/Root.tsx`:

```tsx
<Composition
  id="MyTrip-916"
  component={MyTrip}
  durationInFrames={totalFrames}
  fps={30}
  width={1080}
  height={1920}
/>
```

For 16:9 adaptation, add:
```tsx
<Composition
  id="MyTrip-169"
  component={MyTrip}
  durationInFrames={totalFrames}
  fps={30}
  width={1920}
  height={1080}
/>
```

---

## Step 7: Build in Studio

```bash
npm run studio
```

Open `MyTrip-916` in Remotion Studio and:
1. Preview the sequence
2. Adjust shot lengths and beat positions
3. Tune transitions and timing
4. Verify contact sheet matches the edit

---

## Step 8: Render final

```bash
npm run render-final my-trip --format 9:16
```

Or for 16:9:
```bash
npm run render-final my-trip --format 16:9
```

## Available components for montages

| Component | Purpose | File |
|---|---|---|
| `TitleCard` | Opening title with subtitle | `src/components/TitleCard.tsx` |
| `LocationLabel` | Place/date overlay | `src/components/LocationLabel.tsx` |
| `Stage` | Full-screen clip with zoom-through | `src/components/Stage.tsx` |
| `BeatCut` | Beat-aligned clip sequencer | `src/components/BeatCut.tsx` |
| `ClipTransition` / `ClipTransitionIn` | Fade, dissolve, wipe, zoom-through | `src/components/Transition.tsx` |
| `BeatCutTransition` | Paired clips with beat-aligned transition | `src/components/Transition.tsx` |
| `HighlightMark` | Accent bar behind key phrase | `src/components/HighlightMark.tsx` |
| `KineticSlam` | Overshoot text entrance | `src/components/KineticSlam.tsx` |

---

## Transition types

| Type | Effect | Duration (default) |
|---|---|---|
| `fade` | Cross-fade between clips | 400ms |
| `dissolve` | Smooth cross-fade | 400ms |
| `wipe-left` | Slide right, revealing next clip | 400ms |
| `wipe-right` | Slide left, revealing next clip | 400ms |
| `zoom-through` | Quick push-in at cut point | 400ms |

## Beat mapping

Beat detection options:

| Method | Command | Quality |
|---|---|---|
| aubio (best) | `pip install aubio` | Accurate BPM + beat times |
| ffmpeg transients | Built-in with `prep-montage` | Approximate, good for timing |

Beat map output (`beat-map.json`):
```json
{
  "music": "track.mp3",
  "duration": 124.5,
  "totalFrames": 3735,
  "fps": 30,
  "bpm": 128,
  "beatCount": 265,
  "method": "aubio",
  "beats": [0, 14, 28, 42, ...]
}
```

## Folder structure for montages

```
assets/projects/[name]/
  BRIEF.md              ← filled brief
  broll/                ← source clips
    clip1.mp4
    clip2.mp4
  audio/
    music.mp3
  screenshots/          ← contact sheets (generated by prep)

work/[name]/
  prep/
    PREP.md             ← generated prep report
    refs/
      contact-sheet.png  ← b-roll screenshots
      beat-map.json      ← music beat positions

src/videos/[name]/
  index.tsx             ← your composition

out/[name]/
  [name].mp4            ← final render
```

---

## Tips

- 9:16 is the primary format (1080×1920) — copy montage-template scaffold
- Keep clips short (3-5s each) for social media pacing
- Cut on beats — it feels professional
- Use `Stage` with `zoomThrough` for jump-cut hiding
- Add a title card (3s) at the opening
- Keep transitions under 500ms for energetic pacing

---

## Differences from talking-head workflow

| | Talking head | Montage |
|---|---|---|
| Prep | `npm run prep [name]` | `npm run prep-montage [name]` |
| Transcription | whisper.cpp word timestamps | No transcription needed |
| Beat mapping | Not applicable | `npm run beat-map [name]` |
| Contact sheets | Reference moments only | B-roll clip screenshots |
| Audio | Voice + SFX | Music only |
| Composition | Scene-based talking head | Beat-aligned clip sequencer |
| Typography | Kinetic headlines | Title card + optional labels |
| Transitions | Zoom-through jump cuts | Fade/dissolve/wipe/zoom |
