# assets/

Shared media used across every video.

| Subfolder | Contents | Who fills it |
|---|---|---|
| `fonts/` | Custom font files (.ttf, .otf) | You |
| `logos/` | Brand logos (PNG/SVG, transparent) | You |
| `sfx/` | Sound effects (WAV/MP3) | You |
| `music/` | Music tracks (WAV/MP3) | You |

Per-video media (footage, b-roll, screenshots) lives in `assets/projects/[video-name]/`.
Do not edit files here while a render is running.
