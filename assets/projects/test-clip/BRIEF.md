## Effects library

| Name | What it looks like |
|---|---|
| Word-by-word captions | Each word appears highlighted in time with your voice |
| Zoom-through cut | Quick push-in centred on a jump cut, hides the edit |
| Rolling number | Digits roll from old to new value (counters, stats) |
| Highlight marker | Accent bar wipes behind a key phrase |
| Headline to pill | Large title compacts into a rounded pill |
| Browser mockup | Clean browser frame around a screenshot, pan/zoom |
| Pointer click | Arrow glides to a point and clicks with a ripple |
| Side card | Footage slides into a card beside text |
| Counter race | Two numbers race side by side |
| Colour flip | Background flips between two palette colours |
| Beat cut | Clips cut on detected music beats |
| Title card | Clean typographic opening card for montages |
